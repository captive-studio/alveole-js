# Triage Labels

Les skills utilisent cinq rôles de triage canoniques. Ce tableau les associe
aux labels du projet Jira.

| Label dans mattpocock/skills | Label dans Jira   | Signification                                  |
| ---------------------------- | ----------------- | ---------------------------------------------- |
| `needs-triage`               | `needs-triage`    | Un mainteneur doit évaluer le ticket            |
| `needs-info`                 | `needs-info`      | Informations complémentaires attendues         |
| `ready-for-agent`            | `ready-for-agent` | Prêt pour une implémentation autonome           |
| `ready-for-human`            | `ready-for-human` | Nécessite une implémentation humaine            |
| `wontfix`                    | `wontfix`         | Ne sera pas traité                              |

Lorsqu'un skill mentionne un rôle de triage, utiliser le label Jira correspondant
dans ce tableau.
